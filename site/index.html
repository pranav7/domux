Run all your coding agents from one terminal

domux is a terminal multiplexer for AI coding agents, with a map of every one you run. Give each agent its own git worktree, see which one is waiting on you, and close the lid while the rest keep working. Your tmux keys, on macOS and Linux.

$ curl -fsSL https://domux.dev/install.sh | sh
Read the release notes →

What you get

Ten agents, and you still know where each one is.

01

A worktree for every agent.

A project is a git repository, and a workspace is a worktree in it on its own branch. .domux/worktree.conf links in what a fresh checkout lacks, such as .env and node_modules, and runs your setup. Start an agent in each workspace and no two share a checkout.

$ cat .domux/worktree.conf
link .env
link node_modules
run  pnpm install

03

Read the recap before you switch.

A Claude Code row carries the session's name and the last recap the agent wrote. The switcher and domux peek show both, so you know what an agent did before you go and look.

  claude · domux › auth-cleanup › 1  (a_3f2e)

04

Close the lid. Nothing stops.

A server owns every pane, so detaching or closing the terminal stops no agent, and you attach again from any terminal, over ssh included. Stay awake keeps the machine up with the lid shut; the installer offers to set it up.

 1 auth-cleanup   2 billing-export  3  +            18:57  Sun 14 Sep ●

                            ┌────────────────────────┐
                            │ Stay awake turned on   │
                            └────────────────────────┘

# the next morning, from another machine
$ ssh studio
$ domux
attached: 3 agents, 2 of them still working
05

Your tmux keys, and your mouse.

Tabs, splits, zoom, scrollback and copy mode answer the keys you already know, behind a leader you pick at install. The wheel scrolls, a drag selects, a click opens the link under it, and a program that asked for the mouse gets it.

leader \   split right      leader z   zoom
leader -   split down       leader [   copy mode
leader t   new tab          leader d   detach
leader a   agents           leader s   search
leader b   hide the sidebar leader ?   every key

C-h C-j C-k C-l   move between panes

wheel scrolls · drag selects · click opens the link under it
06

Scriptable by you, and by your agents.

Every key, subcommand and API call reaches the same handler, so anything you can press you can script: domux events streams what happens as JSON, and domux pane send-text types into a pane. Every agent starts with a note saying where it is and how to ask domux who else is running.

$ domux events 'agent.*'
{"event":"agent.state_changed","agent":"a_3f2e","from":"working","to":"waiting"}
{"event":"agent.recap_changed","agent":"a_3f2e","recap":"Replaced the session…"}

And the rest

  • Themes. Your terminal's colours, a theme file of your own, or the built-in look. On Omarchy the chrome follows a theme change while you stay attached.
  • Pull requests. Each workspace row shows its branch and the number of its open pull request.
  • Hooks, set up for you. The command that installs domux finds Claude Code, Codex and OpenCode and installs the hooks each one reports through. Run it again to upgrade.
  • domux open <path> registers a repository as a project and switches to it.
  • No tmux to install. domux is its own multiplexer, so a fresh machine needs the one binary.
  • Open source. Apache-2.0, on GitHub.
